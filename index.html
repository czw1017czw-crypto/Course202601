▾场地口径与修改说明 点一下展开 / 收起

· 周次按校历标注：下拉里的每一周都直接写出起止日期（如「第 5 周（9月28日–10月4日）」），第 1 周周一为 2026 年 8 月 31 日。打开程序时默认定位到今天所在的周次，方便直接核对。
· 上课教师按年级分段：教师卡片分 24级 / 25级 / 26级 三段排列，每段自带标题与「几位教师·几节课」，一眼看清各年级段当节的上课情况，不再混排。
· 范围筛选：可勾选 24级 / 25级 / 26级 / 专体班 / 选项教学 / 选修·融合，多选取并集，「全部勾选」恢复全量；不勾任何一项＝显示全部。专体班＝24、25、26 级「休闲体育服务与管理」班合并成一类。
· 卡片两种形态：
　　选项教学卡（蓝底「选项教学」标签）＝25/26级选项课，只显示任课教师 + 所授项目 + 选项人数 + 场地，项目取自 112.xlsx 的 28 张时段页；
　　行政班卡＝24级、专体班、选修/融合，以及该时段给行政班上体育课的老师，班级、班主任、教室、任课教师都保留。红底「行政班」标签＝选项时段内为未选上志愿学生另开的行政班体育课，需特别关注。
· 固定场地：25/26级选项教学的篮球、羽毛球、乒乓球，按《场地分配方案 · 2-固定场地(全学期不变)》逐条落到具体编号（室内篮球场1、室内篮球馆2、室内羽毛球1-2、室内乒乓球场1-2）。
· 修改选项教学的项目名称 / 人数：选项教学卡上项目名与人数右侧有 ✎ 小按钮，点开后需先输入管理密码（与「清空全部地点修改」同一个密码），验证通过后出现「项目名称 + 人数」两个输入框，可只改其中一项、也可两样一起改（如「篮球」→「篮球（男）」、「40人」→「43人」）。保存后卡片显示新项目名（标「·已改名」）与新人数（紫底），导出地点表格、教师详情、督导记录与上方「本时段选项教学安排」都会同步；点「恢复原名原名额」即还原。修改只针对该教师该时段这一节课，全学期生效、与周次无关，保存在本机浏览器，可随「备份全部数据」一起导出。同一浏览器会话内验证一次即可，刷新页面后需重新验证。
· 室外场地编号（含室外场地编号表）：按《6-室外场地席位表(逐时段)》逐时段逐班落到具体编号——足球→室外足球场1、排球→室外排球场1／2／3、羽毛球→室外羽毛球场1／2、匹克球→室外匹克球场1／2、篮球→室外篮球场1。标「固定（全学期不变）」的整学期都在该室外场；标「轮换（每周换班）」的只在列出的周次到室外，其余周次回室内按号排（上方选定周次即可看到本周到底是室内几号还是室外几号）。
· 选修课/融合课：按项目名匹配场地——匹克球→室外匹克球场1、2…、足球→室外足球场1，其余（羽毛球／篮球／乒乓球／气排球／排球裁判／健身达人／职业体能／啦啦操）为室内场地；同一时段同项目多班依次编号。
· 专体班（休闲体育服务与管理）：不论年级，一律按所学项目统一到对应场地——匹克球→室外匹克球场、足球→室外足球场、篮球→室内篮球馆、排球→室外排球场、羽毛球／乒乓球→室内场、四项（田径）→400米操场；理论课与自习就在本班教室。同一时段同项目多班依次占号，并自动避开已被选项教学占用的场地号。
· 24级（高三）公共体育：排课口径统一按室外，具体地点一律留空，由任课教师点「✎ 填地点」自行填写并保存（输入框中会提示原课表登记的场地，仅作参考）。24级与专体班是两个独立范围，此留空规则不用于专体班。
· 行政班体育课：25/26级选项时段内，为未选上志愿学生开设的行政班体育课（112.xlsx 中的「行政班教师」），地点标注为「行政班 · 地点待定」，由任课教师自行填写并保存。
· 场地颜色：红色＝室外，青色＝室内，灰色＝未填写／待定。
· 地点重复自动提醒：同一时段内若两处（及以上）填了同一个具体场地，程序会整体标红，并在该课旁与页面顶部提示「⚠ 已重复，请重新填写地点」，请相关教师点「✎ 改地点」改开。未填写／行政班待定等占位状态不参与重复判定。
· 选项课人数口径：卡片上显示的是该教师本人带的学生数（取自 112.xlsx 逐学生明细的「项目任课教师」列），鼠标悬停可看本项目合计数；如有人转项导致人数变动，可用卡片上 ✎ 按钮改写（需管理密码）。
· 地点填写状态标识（姓名+年级旁的小按钮）：绿色「✎ 填地点」＝地点尚未填写或仍为系统推定，需要落实；灰色「✎ 改地点」＝地点已明确（场地分配表／室外场地编号表／选修课项目匹配／教师人工设定），点开可随时修改。
· 地点可无限次改写：点「✎ 填地点／改地点」→ 输入任意文字 →
　　没有选周次时，保存＝全学期固定（该课所有周都改用新地点）；
　　选了周次时，可「保存到第 N 周」（只改这一周，其余周仍按方案轮换）或「保存到全学期」。内容与次数都不限，随时可「恢复默认」。
· 导出 / 导入地点表格（统一模板 · 可无限次往返）：点「导出地点表格」先展开导出设置，可以选导出哪些内容 （全部排课记录／仅当前时段）与班级范围（24级／25级／26级／专体班／选项教学／选修·融合，多选）， 面板上会实时显示本次共几条记录；
　　再选保存到哪：首选「⤓ 下载表格文件（推荐）」——文件进浏览器默认「下载」文件夹，按 Ctrl+J 可打开下载列表， 最稳、不会出现空文件；也可点「💾 选择保存位置…（电脑）」弹出系统「另存为」窗口自选文件夹（部分电脑上会存出空白文件， 程序会自动删掉空文件并改走下载）。不管点哪条通道，导出后表格内容都会直接显示在页面下方， 你可以肉眼确认数据非空，也能「📋 复制全部内容」手动粘到 Excel。
　　导出的是 CSV，Excel / WPS 双击即开（中文不乱码）。表内只填【新地点】列：留空＝这一行不动，填「-」＝恢复系统默认， 其余列（尤其末列「记录键」）请勿改动；填好后用 Excel「另存为 → CSV UTF-8（逗号分隔）」保存， 再回程序点「导入地点表格」选择该文件即按行生效（行序可随意调整、删行也不影响其它行）；导入范围是全学期， 次数不限。
· 督导查课点评：每张教师卡片右上角都有「✎ 点评」按钮。点它 → 输入督导密码 → 即可写下本节课的听课 / 评课意见。
　　保存后，点评以红色字体显示在这节课的卡片上，同时按钮变成红色的「已评」；没有点评就不显示任何标记。可随时再点「已评」修改或删除。
　　密码验证通过后本次开启长期有效（不必每节课都输），页面顶部会出现「督导模式已开启」提示条，点点评条上的「退出督导模式」即可重新上锁。督导点评保存在本机浏览器，供本机查看。
· 督导记录统计 / 一键下载（学期末归档用）：「地点表」那行有个「📋 督导查课记录」按钮（带红色条数徽标），点开即是全学期统计—— 共多少条点评、覆盖多少位教师与时段、涉及多少节课，并按年级 / 星期 / 教师分别列出分布，另有「最近一条」时间。
　　点「⤓ 直接下载」或「选择保存位置…」即可导出 体育督导查课点评汇总_日期.csv，一行一条点评，内容包括： 点评时间、星期、节次、周次、年级、类别、班级、项目/课程、任课教师、班主任、教室、地点，以及督导点评原文； 文件开头还会附上按年级 / 按星期 / 按教师的统计与地点口径，可直接交给督导室归档。
　　同一教师同一时段有多个班时，班级/项目/地点等列会用「、」合并在一行里。需要地点按某一周精确解析（如轮换课的当周场地）， 先在顶部选好周次再导出；不选周次则自动把轮换课展开成各周区间。归档完成后可用「🗑 清空全部督导点评」清空（需验证密码）。
· 修改保存在本机浏览器（换电脑／换浏览器不通用），随时可「恢复默认」。「清空全部地点修改 / 选项教学修改」需验证密码（防止误触清掉全校教师的填写），点按钮后输入密码再「确认清空」。
